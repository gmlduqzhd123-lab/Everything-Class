# 초등 수업 대백과

초등 1~6학년 교과, 창의적 체험활동, 계기교육용 유튜브 영상 자료실입니다. 교사는 공개 주소에서 학년·교과·학기와 검색어로 자료를 찾고, 영상을 재생하거나 상세 링크를 공유할 수 있습니다.

## 운영자가 영상을 등록하고 공개하는 방법

자동 반영을 연결한 뒤에는 비공개 관리 시트의 **영상 관리** 탭에서 한 영상당 한 줄을 입력하고 검수 후 상태를 `공개`로 지정하면 됩니다. 영상을 내릴 때는 `비공개`로 바꿉니다. Google 웹 게시가 갱신된 뒤 사이트를 열거나 새로고침하면 최신 공개목록이 표시됩니다. Google 스프레드시트의 공개본 갱신에는 몇 분이 걸릴 수 있습니다.

### 자동 반영 최초 설정

1. 스프레드시트 파일을 두 개 사용합니다. 기존 관리 파일은 공유를 **제한됨**으로 유지합니다. 복사 대상 파일은 **사이트 공개목록** 탭 하나만 두고, 편집 권한을 운영자에게만 부여합니다.
2. 관리 시트에서 **확장 프로그램 → Apps Script**를 엽니다. [동기화 스크립트](google-apps-script/CatalogSync.gs)를 붙여 넣고 `PASTE_PUBLIC_SPREADSHEET_ID`를 복사 대상 파일 주소의 `/d/`와 `/edit` 사이 값으로 바꿉니다. 저장 후 `installCatalogSync`를 한 번 실행하고 Google이 요구하는 권한을 승인합니다.
3. 복사 대상 파일에서 실제 공개할 영상만 들어왔는지 확인합니다. **파일 → 공유 → 웹에 게시**에서 **사이트 공개목록** 탭과 **쉼표로 구분된 값(.csv)**을 선택합니다. **변경될 때 자동으로 다시 게시**를 켜고 게시 주소를 복사합니다. 관리 파일에서는 웹 게시를 사용하지 않습니다.
4. GitHub **Settings → Secrets and variables → Actions → Variables**에 저장소 변수 `PUBLIC_CATALOG_CSV_URL`을 만들고 3단계에서 받은 주소를 넣습니다. **Actions → Deploy elementary lesson library → Run workflow**를 한 번 실행해 연결을 확인합니다.
5. 사이트는 방문할 때 최신 공개목록을 불러와 검사합니다. 목록을 불러오지 못하거나 검증에 실패하면 마지막 GitHub Pages 배포본이 표시됩니다. GitHub Actions도 5분 간격으로 목록 갱신을 예약하며, 오류는 Actions 실행 로그에 표시됩니다.

공개목록에서 게시한 데이터는 사이트의 공개 영상 정보와 같습니다. 비공개 상태인 행과 관리 탭은 복사 대상에서 제외됩니다. Apps Script와 GitHub Actions가 실행되므로 작업용 PC를 켜 둘 필요가 없습니다.

### 자동 연동 전 수동 배포

1. 비공개 관리 시트의 **영상 관리** 탭에 한 영상당 한 줄을 입력합니다. 검수 전에는 상태를 `검수중`으로 둡니다.
2. 주제와 대상 학년이 맞는지 확인하고, 로그아웃 상태에서 원본과 삽입 플레이어의 재생을 확인합니다. 확인일을 기록한 뒤 상태를 `공개`로 바꿉니다.
3. **공개목록** 탭을 열고 **파일 → 다운로드 → 쉼표로 구분된 값(.csv, 현재 시트)**을 선택합니다. 공개목록에는 공개 상태인 행만 표시됩니다.
4. 받은 파일 이름을 `videos.csv`로 바꿉니다. GitHub 저장소에서 **Add file → Upload files**로 `catalog` 디렉터리 안의 기존 `videos.csv`를 교체하고 `main`에 커밋합니다. Git으로 반영할 때도 같은 경로를 사용합니다.
5. **Actions → Deploy elementary lesson library**에서 성공 여부를 확인합니다. 검증에 실패하면 상세 로그에 행 번호와 수정할 항목이 나오며, 공개 사이트에는 마지막 정상 배포본이 표시됩니다.
6. 공개 주소에 새 영상이 표시되는지 다른 브라우저에서 확인합니다. 영상을 내릴 때는 시트의 상태를 `비공개`로 바꾸고 같은 절차로 재배포합니다. 내려간 영상의 기존 공유 주소에는 목록으로 돌아가는 버튼이 표시됩니다.

저장소와 공개 CSV는 인터넷에서 볼 수 있습니다. 비공개 관리 탭, 검수 메모, 개인정보는 저장소에 올리지 마세요. 이전 공개본 복원이 필요할 때는 문제를 일으킨 커밋을 되돌리면 같은 절차로 배포됩니다.

### 영상 목록 입력 형식

| 항목 | 형식 |
| --- | --- |
| 유튜브 링크 | 단일 영상 HTTPS 주소. 같은 영상의 여러 공유 주소도 영상 ID로 중복 검사합니다. |
| 표시 제목·채널명 | 교사용 제목과 원본 채널명 |
| 영상 길이(초) | 전체 길이를 초 단위 정수로 입력. 예를 들어 3분 42초는 `222` |
| 학년·교과 | `4학년:과학` 또는 `4학년:계기교육`. 여러 조합은 `3학년:계기교육 \| 4학년:계기교육`처럼 입력. 통합교과는 바른 생활·슬기로운 생활·즐거운 생활 중 해당 교과를 입력 |
| 수업 주제·수업 활용 팁 | 교육 내용과 교실에서 해 볼 활동. 줄을 바꾸어 `수업 질문 · …`을 덧붙일 수 있습니다. |
| 마지막 확인일 | `YYYY-MM-DD` |
| 학기·단원 | 선택. 학기는 `1` 또는 `2`. 한 학년·교과의 단원은 그대로 입력. 영상 하나를 여러 단원에 연결할 때는 `3학년:체육=1/1. 운동 \| 4학년:체육=1/1. 운동` 형식 사용. 학기 칸이 비어 있을 때 `/` 앞을 비우면 학기 공통으로 분류 |
| 검색 태그 | 선택. `얼음 \| 융해`처럼 구분. 수업 단계는 `단계:도입`, `단계:개념 설명`, `단계:활동`, `단계:정리`를 사용합니다. 영상 유형은 `유형:설명형`, `유형:실험·시범`, `유형:애니메이션`, `유형:현장·사례`, `유형:동요·율동`, `유형:문제 풀이`를 사용합니다. 계기교육 활용 월은 `4월 \| 6월`처럼 각각 입력합니다. |
| 시작(초)·종료(초) | 선택. 시작만 두면 그 시점부터 재생. 종료를 쓰려면 시작도 입력 |

학년과 교과를 함께 선택하면 영상이 등록된 단원으로 좁혀 볼 수 있습니다. 검정 교과는 [아이스크림미디어 2022 개정 교과서 진도표](https://text.i-scream.co.kr/user/information/communityList.do), 국정 교과는 [교육부 국정도서](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=316&boardSeq=95173&lev=0&m=0302) 목차를 기준으로 분류합니다.

- 사이트의 **단원별 자료 현황**에서 기준 단원의 등록 영상 수, 도입 영상 수, 마지막 확인일이 90일 지난 영상 수를 볼 수 있습니다.
- 단원을 선택하면 **단원 추천 영상**이 검색 결과 위에 표시됩니다. 운영자는 단원별로 `단계:도입|추천:도입`과 `단계:정리|추천:정리`를 각각 한 영상에 지정하고, 영상 형식에 맞는 `유형:` 태그를 함께 입력합니다. 영상이 여러 단원과 연결돼 있으면 추천 태그가 각 단원에 적용됩니다.
- **내 수업 영상함 → 수업 꾸러미**에서 최대 12편을 순서대로 담고 링크를 공유할 수 있습니다. **교실 화면 열기**로 큰 화면에서 첫 영상을 열고, 이전·다음 버튼으로 이동합니다.
- 영상함의 **백업 내보내기**로 즐겨찾기와 꾸러미를 담은 JSON을 저장합니다. 다른 브라우저의 **백업 가져오기**는 기존 영상함에 새 항목을 추가합니다. 같은 즐겨찾기와 같은 이름·영상 순서의 꾸러미는 한 번만 가져옵니다.
- 관리 파일의 **운영 현황 → 사이트에서 목록 비교** 또는 사이트 하단의 **목록 갱신 상태**에서 공개·예비 목록을 확인합니다. 영상 수가 같아도 유형과 수업 단계가 다른 영상 수를 각각 표시합니다. GitHub Actions는 배포 뒤 공개 주소의 목록과 배포 버전이 빌드 결과에 일치하는지 검사합니다.
- 작은 화면에서는 학년과 교과·활동을 먼저 선택할 수 있습니다. 학기, 단원, 영상 길이, 수업 단계와 영상 유형은 **상세 조건**을 열어 선택합니다.

### 재생 오류 점검과 대체 영상 게시

1. 관리 파일의 **재생 오류 신고** 탭에서 새 응답을 찾습니다. **처리 상태**와 실제로 앱 안에서 확인한 **재생 점검 결과·일자**를 입력합니다.
2. 결과가 `교체`이면 같은 학년·교과·학기·단원에 등록된 공개 영상의 ID를 **대체 영상 ID**에 입력합니다. **반영할 검색 태그**에는 기존 태그에 `재생:교체|재생확인:YYYY-MM-DD|대체:영상ID`를 적용한 값이 생성됩니다.
3. **영상 관리 링크**를 열어 해당 **검색 태그** 셀에 생성된 값을 붙여넣습니다. 사이트에서 공개 목록 갱신과 대체 영상을 확인한 뒤 **처리 상태**를 `반영 완료`로 바꿉니다. 같은 단원의 지정 영상이 표시 가능하면 먼저 나오며, 그 외에는 같은 단원 후보를 보여줍니다.

### 영상 유형과 수업 단계 검토

1. 비공개 관리 파일의 **분류 검토** 탭에서 `검토 대기`인 영상을 확인합니다. **분류 근거**와 원본 영상을 보고 **영상 유형 제안**과 **수업 단계 제안**을 고칩니다. 사용할 분류가 없으면 해당 칸을 비웁니다.
2. **반영할 검색 태그**를 복사하고 **관리 태그 열기**를 선택합니다. **영상 관리**의 해당 검색 태그 셀에 **값만 붙여넣기**로 반영한 뒤, 검토 상태를 `반영 완료`로 바꿉니다. 검토 탭의 수정은 후보에만 적용됩니다.
3. 후보를 더 만들려면 공개목록 CSV로 `node scripts/suggest-classifications.mjs 공개목록.csv 검토목록.tsv 60`을 실행합니다. 제목과 태그에 분류 단서가 있는 영상을 학년·유형별로 골라 제안합니다. TSV의 A~H열을 기존 **분류 검토** 아래에 추가한 뒤 I~J열 수식을 새 행에 채웁니다.

## GitHub Pages에서 시작하기

- 소스는 별도 백엔드와 API 키가 필요 없는 정적 사이트입니다.
- 다른 저장소에서 운영하려면 기본 브랜치를 `main`으로 두고 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다. 이후 `main`에 푸시하거나 Actions에서 워크플로를 한 번 실행합니다.
- Node.js 22 이상에서 `npm run build`를 실행하면 CSV를 검증하고 `dist`에 배포 파일을 생성합니다. `npm run preview`를 실행하면 로컬 브라우저에서 확인할 수 있습니다. 패키지 설치는 필요 없습니다.

유튜브 영상 상태는 게시 이후 달라질 수 있습니다. 학기 초에 로그인하지 않은 학교 PC와 학교 네트워크에서 재생을 다시 확인하고, 막힌 영상은 원본으로 열어 보거나 교체하세요. 학교 네트워크에서 YouTube 연결이 차단된 경우 재생에는 학교 네트워크 설정 확인이 필요합니다.

교육과정 기준은 [교육부 고시 제2022-33호](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&statusYN=W)입니다.
